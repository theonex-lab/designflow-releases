# Assets do DesignFlow

Comece em [`../README.md`](../README.md) e [`../assets.md`](../assets.md). Nesta pasta estão tokens, contratos estruturados, ícones, componentes React e 10 PNGs de referência.

- `design-tokens.json`: fonte de valores; gerar CSS com `../scripts/generate_css_tokens.py`.
- `screen-contracts.json`: matriz de telas, rotas, seções e estados.
- `flows.json`: fluxo semântico de eventos e resultados.
- `contracts/domain.ts`: tipos de domínio sem backend.
- `ui/`: kit de componentes sem dependência de APIs externas além de React e Lucide.
- `references/`: guias estéticos e de hierarquia, não produto nem conteúdo real.
